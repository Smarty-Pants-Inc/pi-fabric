## Default budgets and effect-time gates

Slack for an 11 s block with measured pre-stall age `a`: freshness slack = `10 − a − 11` seconds; resident lease slack = `15 − a − 11`. Near the normal next renewal, `a ≈ 5`, so return is near age 16 s: ~6 s beyond freshness and ~1 s beyond lease. These are nominal steady-state calculations, not scheduler guarantees; arbitrarily delayed initial state has no positive guaranteed slack. A ≥30 s block crosses both by much more.
